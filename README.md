## Project Overview
This repository contains our modernized MNE-Python pipeline designed to replicate and upgrade the methodology presented in *"Symmetry perception and affective responses: A combined EEG/EMG study"*. 

We analyze the Sustained Posterior Negativity (SPN) effect using the BioSemi64 BIDS dataset (`ds004347`). To ensure the highest standards of data integrity and statistical rigor, we have implemented several methodological upgrades from the original paper:
1. **Targeted Artifact Exclusion:** We actively dropped inconsistently labeled EXG (muscle) channels to prioritize EEG data integrity.
2. **Modernized Filtering & Baseline:** We utilize a strict 0.5–30.0 Hz band-pass filter and a -200ms to 0ms pre-stimulus baseline to prevent artifact and post-stimulus VEP bleeding.
3. **Advanced Statistics:** We replaced the original standard ANOVAs with a robust 1-sample Spatio-Temporal Cluster Permutation Test to elegantly handle the multiple comparisons problem across space and time.

## Prerequisites & Installation

To run this pipeline, you will need a standard scientific Python environment. We recommend Python 3.9+.

**Required Packages:**
```bash
pip install mne mne-bids numpy pandas matplotlib

Step-by-Step Execution Guide
Follow these exact steps to reproduce our preprocessing, feature extraction, and statistical analysis.

Step 1: Configure the Dataset Path
Before running any scripts, you must point the pipeline to the location of the downloaded BIDS dataset on your local machine.

Open config.py in your code editor.

Locate the BIDS_ROOT variable at the top of the file (around Line 22).

Change the path to match the directory where the ds004347 dataset is stored on your system:
# Example:
BIDS_ROOT = Path("/path/to/your/local/dataset/ds004347")

step 1.1: Run Automated Sanity Checks
Verify the mathematical logic of the SPN extraction and the integrity of the preprocessing parameters:
```bash
python test_pipeline.py

Step 2: Run the Main Preprocessing & ERP Pipeline
To process all 24 subjects, extract the SPN metrics, and generate quality control figures, run the master script from the root of the project directory:
#(make sure you are in scripts folder or provide path to this file while running this command)
python run_all_subjects.py

This command automates:

  Preprocessing: Filtering (0.5-30Hz), ICA artifact rejection, and bad channel interpolation.

  Metric Extraction: Saving individual quantitative summaries for all subjects.

  Group Visuals: Generating Grand Average line plots, Topographic maps, and Alpha-Band ERD.

If you wish to test the pipeline on a single subject (eg. sub 005), you can run:
python run_subject.py --subject 005

Step 3: Run the Group-Level Statistical Analysis
Once run_all_subjects.py has finished generating the .fif files for all participants, run the group-level statistics to verify the SPN effect:
python cluster_perm_test_group.py

Step 4 (Optional): Subject-Level Verification
We have also included a highly modular subject-level permutation test in our package (cluster_perm_test_subject.py). While our primary inferences are drawn at the group level, this script can be imported and run if you wish to rigorously verify the SPN effect within individual participants.

## Output Structure
After running the pipeline, the `derivatives/eegtigers/` directory will be structured as follows:

* `/sub-XXX/`: Contains the preprocessed MNE Epochs (`_epo.fif`) and the averaged Evoked files (`_ave.fif`).
  * **`sub-XXX_summary.json`:** This is a critical output file. It contains the extracted quantitative SPN metrics (symmetry mean, random mean, and net SPN difference in µV) alongside the specific bad channels and ICA components excluded for that subject.
* `/figures/sub-XXX/`: Contains all visual quality control plots, including PSD comparisons, ICA component topographies, and ERP difference waves.
* `/stats/`: Contains the `.txt` summaries and `.npy` data arrays generated by the Spatio-Temporal Cluster Permutation Tests.
